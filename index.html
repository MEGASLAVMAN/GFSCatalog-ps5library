🧠 Glossário Técnico (Kernel & Exploit)

Use-After-Free (UAF): Falha que ocorre quando o sistema libera um espaço de memória (Free), mas o programa continua com um ponteiro ativo tentando usar (Use) aquele endereço corrompido.

Kernel Exploit (Ex: P2JB / Luac0re): Código projetado para quebrar a segurança do núcleo do sistema operacional, elevando os privilégios do usuário comum para o nível máximo (Root/Administrador).

Hypervisor / Slopervisor: Camada ultra-protegida de hardware/software instalada pela Sony queurosupervisiona o Kernel. Em firmwares como o 13.60, ela impede modificações no sistema mesmo após um Kernel Exploit, exigindo ataques físicos por hardware (glitching) para ser derrotada.

Payload (.bin): A carga útil ou o programa executável de modificação (como o etaHEN) que é transmitido via rede para ativar funções de homebrew e Debug Settings na memória RAM liberada do PS5.
